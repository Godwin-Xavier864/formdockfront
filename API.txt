# API v1 Documentation

Base URL: `http://localhost:8000/api/v1/`

Scope:
- This document contains only user-side/public integration APIs.
- Admin/staff APIs are intentionally excluded from this file.

Authentication:
- JWT (recommended for React): `Authorization: Bearer <access_token>`
- Session (for dashboard users)

All endpoints below require authentication unless marked Public.

---

## Auth (Public)

### Register
`POST /api/auth/register/`
```json
{ "username": "demo", "email": "demo@example.com", "password": "1" }
```

### Login (JWT)
`POST /api/auth/token/`
```json
{ "username": "demo", "password": "1" }
```
Response:
```json
{ "access": "...", "refresh": "..." }
```

### Refresh
`POST /api/auth/token/refresh/`
```json
{ "refresh": "..." }
```

### Email Verify
`GET /api/auth/email/verify/?token=...`

## Me

### Current User
`GET /api/v1/me/`
Response:
```json
{
  "id": "uuid",
  "username": "demo",
  "email": "demo@example.com",
  "email_verified": false
}
```

### Delete My Account
`DELETE /api/v1/me/`

If user has active subscription, API returns:
```json
{
  "success": false,
  "error": "You have an active subscription and it can't be refunded. Please wait for expiry before deleting your account."
}
```

To delete anyway (no refund), send either:
- Query param: `DELETE /api/v1/me/?force_delete=true`
- Or body: `{ "force_delete": true }`

`PATCH /api/v1/projects/<uuid>/`

## Form AI Rewrite Tool

### Rewrite HTML Using Groq
`POST /api/v1/tools/form-rewrite/`
```json
{
  "project_id": "uuid",
  "html_input": "<!DOCTYPE html><html>...</html>"
}
```
Response:
```json
{
  "rewritten_html": "<!DOCTYPE html><html>...</html>",
  "tries_left": 1
}
```

Notes:
- Hard quota: maximum 2 rewrite attempts per user (shared between API and dashboard tool).
- Returns `429` when limit is exhausted.

## Public Form Submission (Public)

### Submit Enquiry
`POST /api/forms/submit/`
```json
{
  "project_api_key": "YOUR_PUBLIC_API_KEY",
  "fields": {
    "name": "Jane Doe",
    "email": "jane@example.com",
    "message": "Hello there"
  },
  "metadata": {
    "page_url": "https://example.com/contact",
    "referrer": "https://example.com",
    "user_agent": "Mozilla/5.0",
    "timestamp": "2026-02-08T10:00:00Z"
  }
}
```
Response:
```json
{ "success": true, "enquiry_id": "queue_uuid", "locked": false, "queued": true }
```

Status: `202 Accepted`

Versioned alias:
- `POST /api/v1/public/forms/submit/`

Notes:
- Ingest is queue-based; Celery worker flushes queued records in batches.
- Rate limiting is Redis-backed when `REDIS_URL` is configured.

## Public FAQ Chat (Public)

### Ask FAQ Chatbot
`POST /api/faq/chat/`
```json
{
  "faq_api_key": "FAQ_PUBLIC_API_KEY",
  "question": "What is your refund policy?",
  "metadata": {
    "page_url": "https://example.com/faq",
    "user_agent": "Mozilla/5.0"
  }
}
```
Response:
```json
{
  "success": true,
  "chat_id": "uuid",
  "answer": "Refunds are available within 7 days for paid plans.",
  "remaining_quota": 49,
  "test_mode": true
}
```

Notes:
- Uses Groq LLM on backend.
- Backend uses only saved project FAQ config context (from dashboard or `/api/v1/projects/<uuid>/faq-config/`) for site-specific answers.
- Visitor requests cannot submit runtime context.
- `include_collections` can be passed as boolean to include CMS collection data in LLM context.
- Enforces allowed domain checks, DRF throttle, and Redis-backed project+IP limiter.
- Paywall OFF: `50 chats/day` per project + global daily cap `100000` (test mode).
- Paywall ON: paid plan `monthly_chat_quota`; free projects use `FREE_CHAT_LIMIT_WHEN_PAYWALL_ON`.

Versioned alias:
- `POST /api/v1/public/faq/chat/`

## Mini CMS (Public Read)

### Read Collection Data Publicly
`GET /api/collections/public/<collection_slug>/?project_api_key=...&limit=20&page_url=https://example.com/page`

Response:
```json
{
  "success": true,
  "collection": { "id": "uuid", "name": "faq_items", "slug": "faq_items" },
  "limit": 20,
  "entries": [
    {
      "id": "uuid",
      "collection": "uuid",
      "data": { "title": "Refund", "answer": "7 days" },
      "created_at": "2026-03-20T12:00:00Z",
      "updated_at": "2026-03-20T12:00:00Z"
    }
  ]
}
```

Notes:
- Public read requires valid `project_api_key`.
- Allowed domains are enforced.
- Public response limit is capped (`CMS_PUBLIC_READ_LIMIT_MAX`).
- Write/read limits and payload-size caps are enforced by settings.

Versioned alias:
- `GET /api/v1/public/collections/<collection_slug>/?project_api_key=...&limit=20&page_url=...`
