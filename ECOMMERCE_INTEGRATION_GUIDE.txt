           FORMDOCK E-COMMERCE, PRODUCT LISTING & ORDER PLACEMENT GUIDE

Document Version: 1.3.0
API Version: v1
Target Audience: Store Developers, E-Commerce Integrators, Frontend Engineers

--------------------------------------------------------------------------------
1. OVERVIEW & BASE URL
--------------------------------------------------------------------------------
Formdock E-Commerce provides lightweight APIs for displaying product catalogs,
reserving stock, handling Cash on Delivery (COD) and Razorpay Online Payments (BYOPG),
verifying signatures, tracking order delivery, and generating GST-compliant tax invoices.

Base URL (Production): https://api.formdock.in

--------------------------------------------------------------------------------
2. AUTHENTICATION & CREDENTIALS
--------------------------------------------------------------------------------
- Store API Key: `store_api_key` (Found in your Store Configuration settings).
- Razorpay Merchant Webhook URL: https://api.formdock.in/api/v1/store/webhooks/razorpay/

--------------------------------------------------------------------------------
3. ENDPOINT SPECIFICATIONS
--------------------------------------------------------------------------------

3.1 PUBLIC PRODUCT LISTING ENDPOINT
-----------------------------------
Endpoint URL: GET https://api.formdock.in/api/v1/public/products/list/
Query Parameters:
  - store_api_key or project_id (string, required): Merchant store API key.
  - page (integer, optional): Page number for pagination (e.g. 1). Default: 1.
  - page_size or limit (integer, optional): Number of products per page (max 100). Default: 20.

3.2 PUBLIC ORDER CREATION ENDPOINT (CHECKOUT)
---------------------------------------------
Endpoint URL: POST https://api.formdock.in/api/v1/public/orders/create/
Content-Type: application/json

Request Body Parameters:
  - store_api_key (string, required): Your store's public API key.
  - product_id (uuid, required): The ID of the product being purchased.
  - quantity (integer, optional, default: 1): Quantity requested.
  - payment_method (string, optional): "cash" (COD) or "online" (Razorpay). Default: "cash".
  - coupon_code (string, optional): Promotional coupon code (e.g. "SAVE10").
  - selected_variant (object, optional): Key-value variant choices (e.g. {"Storage": "256GB"}).
  - customer_name (string, required): Customer full name.
  - customer_email (email, required): Customer email address.
  - customer_phone (string, optional): Customer phone number.
  - customer_state (string, optional): Customer state name for GST Place of Supply tax calculation (e.g. "Kerala", "Karnataka").
  - customer_state_code (string, optional): 2-digit GST state code (e.g. "32", "29").
  - customer_gstin (string, optional): Customer GSTIN for B2B Tax Invoices.
  - billing_address (string, optional): Customer billing address (defaults to shipping address if omitted).
  - shipping_address (string, optional*): Complete single-line shipping address.
  - address_line1 (string, optional*): Street address / house number (used with structured address).
  - city (string, optional*): City name (used with structured address).
  - state (string, optional*): State or province (used with structured address).
  - pincode (string, optional*): Postal / ZIP code (used with structured address).

*Note on GST & Invoice Generation: Server-side GST tax calculation is automatically executed based on place of supply (Intra-State CGST+SGST vs Inter-State IGST). An immutable tenant sales invoice snapshot is saved, and an itemized GST Tax Invoice / Bill of Supply receipt is emailed to the buyer.

3.3 PUBLIC PAYMENT VERIFICATION ENDPOINT
-----------------------------------------
Endpoint URL: POST https://api.formdock.in/api/v1/public/orders/{order_id}/verify-payment/
Content-Type: application/json

Request Body Parameters:
  - razorpay_order_id (string, required): Razorpay order ID returned from checkout.
  - razorpay_payment_id (string, required): Payment ID returned by Razorpay Checkout modal.
  - razorpay_signature (string, required): HMAC signature returned by Razorpay Checkout modal.

Successful Response (HTTP 200 OK):
{
  "success": true,
  "message": "Payment verified successfully.",
  "order_id": "1943e63a-df31-4771-a18d-4280bfd2e218",
  "tracking_token": "77dd5fe2-6c0a-419c-b941-78c56bee74cd"
}

3.4 MERCHANT TAX CONFIGURATION & INVOICE MANAGEMENT APIs
--------------------------------------------------------
- GET/PATCH /api/v1/projects/{project_id}/tax-settings/
  Configure store GST registration status (REGULAR, COMPOSITION, UNREGISTERED), GSTIN, Legal Name, Address, State, State Code, Tax-Inclusive pricing flag, and Invoice Prefix.

- GET/POST/PATCH/DELETE /api/v1/projects/{project_id}/tax-categories/
  Manage tenant GST tax categories (e.g. Apparel 5%, Electronics 18%, Exempt 0%) with default HSN codes.

- GET /api/v1/projects/{project_id}/invoices/
  Retrieve tenant sales invoices (Tax Invoices and Bills of Supply). Supports filtering by payment_status (PAID/UNPAID), document_type (TAX_INVOICE/BILL_OF_SUPPLY), and search query.

- GET /api/v1/projects/{project_id}/invoices/{invoice_id}/
  Retrieve detailed immutable invoice snapshot with itemized HSN, taxable amounts, CGST/SGST/IGST breakdown, seller snapshot, and buyer snapshot.

- GET /api/v1/projects/{project_id}/tax-report/
  Aggregate taxable sales, CGST total, SGST total, IGST total, total GST, and grand totals for merchant statutory tax filing convenience.
