--------------------------------------------------------------------------------
1. OVERVIEW & BASE URL
--------------------------------------------------------------------------------
Formdock E-Commerce provides lightweight APIs for displaying product catalogs,
reserving stock, handling Cash on Delivery (COD) and Razorpay Online Payments (BYOPG),
verifying signatures, and tracking order delivery.

Base URL (Production): https://api.formdock.in

--------------------------------------------------------------------------------
2. AUTHENTICATION & CREDENTIALS
--------------------------------------------------------------------------------
- Store API Key: `store_api_key` (Found in your Store Configuration settings).
- Razorpay Merchant Webhook URL: https://api.formdock.in/api/v1/store/webhooks/razorpay/

--------------------------------------------------------------------------------
3. ENDPOINT SPECIFICATIONS
--------------------------------------------------------------------------------

-----------------------------------
Endpoint URL: GET https://api.formdock.in/api/v1/public/products/list/
Query Parameter: store_api_key or project_id (string, required)

3.2 PUBLIC ORDER CREATION ENDPOINT (CHECKOUT)
---------------------------------------------
Endpoint URL: POST https://api.formdock.in/api/v1/public/orders/create/
Content-Type: application/json

Request Body Parameters:
  - store_api_key (string, required): Your store's public API key.
  - product_id (uuid, required): The ID of the product being purchased.
  - quantity (integer, optional, default: 1): Quantity requested.
  - payment_method (string, optional): "cash" (COD) or "online" (Razorpay). Default: "cash".
  - coupon_code (string, optional): Promotional coupon code (e.g. "SAVE10").
  - selected_variant (object, optional): Key-value variant choices (e.g. {"Storage": "256GB"}).
  - customer_name (string, required): Customer full name.
  - customer_email (email, required): Customer email address.
  - customer_phone (string, optional): Customer phone number.
  - shipping_address (string, optional*): Complete single-line shipping address.
  - address_line1 (string, optional*): Street address / house number (used with structured address).
  - city (string, optional*): City name (used with structured address).
  - state (string, optional*): State or province (used with structured address).
  - pincode (string, optional*): Postal / ZIP code (used with structured address).

*Note on Shipping Address: You can supply either a full 'shipping_address' string OR structured address fields ('address_line1' and 'pincode' required, plus optional 'city' and 'state'). Structured fields are automatically concatenated into 'shipping_address'.

Example Request Body (Online Payment with Coupon & Structured Address):
{
  "store_api_key": "fd_store_9876543210fedcba",
  "product_id": "8315974d-cfc7-4eb1-b086-e102bc5fd14d",
  "quantity": 1,
  "payment_method": "online",
  "coupon_code": "SAVE10",
  "selected_variant": { "Storage": "256GB" },
  "customer_name": "Jane Smith",
  "customer_email": "jane@example.com",
  "customer_phone": "+919876543210",
  "address_line1": "Flat 402, Highrise Towers",
  "city": "Mumbai",
  "state": "Maharashtra",
  "pincode": "400001"
}

3.3 PUBLIC PAYMENT VERIFICATION ENDPOINT
-----------------------------------------
Endpoint URL: POST https://api.formdock.in/api/v1/public/orders/{order_id}/verify-payment/
Content-Type: application/json

Request Body Parameters:
  - razorpay_order_id (string, required): Razorpay order ID returned from checkout.
  - razorpay_payment_id (string, required): Payment ID returned by Razorpay Checkout modal.
  - razorpay_signature (string, required): HMAC signature returned by Razorpay Checkout modal.

Example Request Body:
{
  "razorpay_order_id": "order_K1x928374619",
  "razorpay_payment_id": "pay_K1x998877665",
  "razorpay_signature": "a8f9b2c3d4e5f67890..."
}

Successful Response (HTTP 200 OK):
{
  "success": true,
  "message": "Payment verified successfully.",
  "order_id": "1943e63a-df31-4771-a18d-4280bfd2e218",
  "tracking_token": "77dd5fe2-6c0a-419c-b941-78c56bee74cd"
}

3.4 MERCHANT WEBHOOK ENDPOINT
------------------------------
Endpoint URL: POST https://api.formdock.in/api/v1/store/webhooks/razorpay/
Description: Paste this Webhook URL into your Razorpay Dashboard under Settings -> Webhooks. Select event `payment.captured`.

3.5 PUBLIC ORDER TRACKING ENDPOINT
----------------------------------
Endpoint URL: GET https://api.formdock.in/api/v1/public/orders/track/{tracking_token}/

3.6 PUBLIC ORDER CANCELLATION ENDPOINT
---------------------------------------
Endpoint URL: POST https://api.formdock.in/api/v1/public/orders/track/{tracking_token}/cancel/
