Target Audience: Store Developers, E-Commerce Integrators, Frontend Engineers

--------------------------------------------------------------------------------
1. OVERVIEW
--------------------------------------------------------------------------------
Formdock E-Commerce provides lightweight, high-performance APIs for displaying product
catalogs, reserving real-time stock, creating orders, tracking shipments, and allowing
customer order cancellations.

Key System Features:
- Custom Product Categories & Sub-Categories: Custom category and sub-category classification.
- Arbitrary Product Variants: Turn variants on/off and define custom attributes (e.g. Colour, Size for Clothes; Storage, RAM, Colour for Electronics).
- Extended Image Uploads: Up to 6 product/variant images per item.
- Atomic Stock Lock: Prevents over-selling during flash sales via Redis stock locking.
- Order Tracking Magic Link: Generates customer tracking URLs instantly on checkout.
- Subscription Gating: Automatically blocks order creation if store subscription is expired.
- Conditional Cancellation: Buyers can cancel orders before dispatch; stock is auto-restored.
- Automated Data Retention: Orders marked completed/delivered are automatically purged after 7 days.

--------------------------------------------------------------------------------
2. AUTHENTICATION & CREDENTIALS
--------------------------------------------------------------------------------
- Store API Key: `store_api_key` (Found in your Store Management Settings).
- Tracking Token: UUID generated automatically per order (e.g. `c712b806-1e2a-4b71-bae3-d3386a266a8e`).

-----------------------------------
Endpoint URL: GET /api/v1/public/products/list/
Header or Query Parameter: store_api_key or project_id (string, required)

3.2 PUBLIC ORDER CREATION ENDPOINT (CHECKOUT)
---------------------------------------------
Endpoint URL: POST /api/v1/public/orders/create/
Content-Type: application/json

Request Body Parameters:
  - store_api_key (string, required): Your store's public API key.
  - product_id (uuid, required): The ID of the product being purchased.
  - quantity (integer, optional, default: 1): Quantity requested.
  - selected_variant (object, optional): Arbitrary key-value variant choices matching product attributes (e.g. {"Storage": "256GB", "Color": "Titanium Black"} or {"Size": "XL", "Colour": "Red"}).
  - customer_name (string, required): Customer full name.
  - customer_email (email, required): Customer email address.
  - customer_phone (string, optional): Customer phone number.
  - shipping_address (string, optional): Complete shipping address string.
  - address_line1, city, state, pincode (strings, optional): Structured address components.

Example Request Body - Electronics (JSON):
{
  "store_api_key": "fd_store_9876543210fedcba",
  "product_id": "8315974d-cfc7-4eb1-b086-e102bc5fd14d",

  },
  "customer_name": "Jane Smith",
